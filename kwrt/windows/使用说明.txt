CFPilot 桌面版（绿色版，含「数据面」多数据面管理）
=====================================================

【怎么用】
  1. 把整个文件夹放到任意位置（例如 E:\代理微内核面板），双击 CFPilot.exe 即可。
  2. 程序会在托盘出现图标并自动打开管理页面。
  3. 不需要安装，也不往 C 盘用户目录写任何东西。拿起整个文件夹就能走。

【文件夹里的东西】
  CFPilot.exe      程序本体
  data\            你的全部数据：Cloudflare 凭据、设置、日志、优选历史、定时任务、优选池、内核缓存
                   → 备份 / 搬家 / 换电脑，复制这个文件夹就行
  updates\         「一键更新」下载的新版本临时放这里

【第一次运行】
  如果你以前用过旧版桌面版（数据在 C:\Users\你的用户名\.cfpilot-gui），
  程序会自动把里面的凭据和设置【复制】到 data\ 里（旧文件原样保留，不会删除）。
  复制只在 data\ 里还没有 secrets.json 时做一次。

【更新】
  「说明」页顶部 → 检查更新 → 有新版就点「下载」，下完点「重启并更新应用」。
  更新来源是你自己的 GitHub 仓库 Releases，不是上游，所以不会丢失多数据面功能。
  更新会自动校验文件摘要，校验不通过会拒绝安装。
  也可以手动：去 Releases 下载新的 CFPilot-windows-portable.zip，
  只替换 CFPilot.exe（data 文件夹别动）。

【和路由器版的分工（建议）】
  - 路由器版：负责定时优选并自动推送；
  - 桌面版：手动管理（添加数据面、部署、查看）。
  两边的数据互相独立，不要两边同时跑定时推送或同时点「部署」。

【注意】
  - 部署内核只用程序自带的内核，不会被换成上游发布的内核。
  - 数据面目录里存有 Cloudflare Token，不要把 data 文件夹发给别人或传到网上。
  - 程序被杀毒软件拦截时，请把本文件夹加入信任（程序没有联网行为之外的任何动作）。
